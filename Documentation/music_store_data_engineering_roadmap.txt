MUSIC STORE DATA ENGINEERING PROJECT
=====================================

Goal
----
Turn the existing Music Store PostgreSQL database into a complete,
end-to-end data engineering portfolio project.

TOOLS TO LEARN
==============

LEVEL 1 - FOUNDATION
--------------------

1. PostgreSQL
   Status: Already installed and working.

   Learn:
   - SELECT
   - WHERE
   - GROUP BY
   - HAVING
   - ORDER BY
   - LIMIT
   - DISTINCT
   - JOIN
   - Subqueries
   - CTEs
   - CASE
   - Window functions
   - Date functions
   - UNION
   - Views
   - Indexes
   - Primary keys
   - Foreign keys
   - Constraints
   - Transactions
   - EXPLAIN
   - EXPLAIN ANALYZE
   - Query optimization


2. Python
   Importance: Very High

   Use Python for:
   - Data extraction
   - Data cleaning
   - Data transformation
   - Data validation
   - Data loading
   - API calls
   - File processing
   - Pipeline automation

   Libraries:
   - pandas
   - psycopg / psycopg2
   - SQLAlchemy
   - requests

   Later:
   - PySpark
   - boto3


3. Git + GitHub
   Importance: Very High

   Learn:
   - git init
   - git clone
   - git add
   - git commit
   - git push
   - git pull
   - git branch
   - git merge

   Suggested project structure:

   music-store-data-engineering/
   |
   +-- dags/
   +-- src/
   +-- sql/
   +-- dbt/
   +-- tests/
   +-- config/
   +-- docker/
   +-- README.md
   +-- requirements.txt
   +-- docker-compose.yml


LEVEL 2 - BUILD A REAL PIPELINE
--------------------------------

4. Docker
   Importance: Very High

   Use Docker to run services in containers.

   Possible containers:
   - PostgreSQL
   - Airflow
   - dbt
   - Spark

   Learn:
   - docker pull
   - docker run
   - docker ps
   - docker exec
   - docker logs
   - docker compose up
   - docker compose down

          v

          v

   Learn:
   - DAG
   - Task
   - Operator
   - Dependency
   - Schedule

   - XCom
   - Variables
   - Connections
   - Backfill

   Final analytics layer.

12. DATA QUALITY

   Important checks:
   - customer_id cannot be NULL
   - invoice_id must be unique
   - invoice total must be >= 0
   - track_id must exist
   - invoice_line must reference invoice

   Tools:
   - dbt tests
   - Great Expectations

MAIN OBJECTIVE
==============

The goal is not simply to learn individual tools.

The goal is to understand how a real data engineering system works
from source data all the way to analytics.

By completing this project, you will practice:

- SQL
- Python
- ETL / ELT
- Data modeling
- Data warehousing
- Cloud storage
- Workflow orchestration
- Data transformation
- Big data processing
- Streaming concepts
- Data quality
- Business intelligence
- Git/GitHub
- Docker
- Production-style project organization
